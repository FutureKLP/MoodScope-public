# Entwicklungs- und Abnahmestand

MoodScope 0.3 ist eine Entwicklungsversion. Automatisierte Regressionen und
Kompilierung ersetzen keine vollständige native Kernabnahme. Maßgeblich sind
[Testbaseline](TEST-BASELINE.md) und [Kernabnahme](CORE-ACCEPTANCE.md).

Windows 10, Linux, Installer, längere Wiedergabe-/Mix-/Speicherprüfungen und die
vollständige native Wechsel-/Neustart-/Dialogfehlermatrix bleiben unbestätigt.
Der native WAV-Exportabbruch benötigt eine kontrollierte erneute Abnahme.
Ein sporadischer Music2Emo-Prüfdienstfehler ist nicht vollständig aufgeklärt.
Zeitliche Emotionsgenauigkeit und Whisper-Wortgenauigkeit sind nicht belegt.
Keine Freigabe für externe Datenbanken oder einen produktionsreifen Installer.
